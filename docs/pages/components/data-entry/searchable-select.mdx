# SearchableSelect（已并入 Select）

`SearchableSelect` 已内化为 [Select](/components/data-entry/select) 门面的 combobox
引擎，**不再从 `@riseaicloud/ui` 导出**（收编时全平台使用数为 0，无迁移成本）。

原有能力全部保留，在 `Select` 上通过 props 使用：

| 原来 | 现在 |
| --- | --- |
| `<SearchableSelect options value onValueChange />` | `<Select searchable options value onValueChange />` |
| `onSearch` 远程搜索 | 同名 props，直接搬 |
| `onLoadMore` / `hasMore` / `loading` 滚动分页 | 同名 props，直接搬（推荐配 `useSelectOptions`） |
| `clearable` / `renderOption` / `filterOption` | 同名 props，直接搬 |
| `SearchableSelectOption` 类型 | 改名 `SelectOption` |
| — | 新增：`multiple` 多选、`checkAlign` 对钩位置 |

相对旧实现的升级：Radix Popover 底座（Dialog / overflow 容器内不再被剪裁）、
完整键盘导航（↑↓ Enter Esc Home/End）、combobox ARIA。

详见 [Select 文档](/components/data-entry/select)。
