# ToggleGroup 切换按钮组

`ToggleGroup` 把多个 `ToggleGroupItem` 组织成一组，支持单选（`type="single"`）或多选（`type="multiple"`），常用于视图切换（列表 / 网格）、时间范围切换等分段控制场景。它是对 `@radix-ui/react-toggle-group` 的薄封装，并通过 Context 把 `variant` / `size` 从组下发给每个子项，保证整组样式一致。

## 引入

```tsx
import { ToggleGroup, ToggleGroupItem } from '@riseaicloud/ui'
```

## Props

### ToggleGroup

继承 `@radix-ui/react-toggle-group` Root 的全部 props，另加变体属性。

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `type` | `'single' \| 'multiple'` | — | 单选或多选（Radix 必填） |
| `value` | `string \| string[]` | — | 受控选中值（`single` 为 `string`，`multiple` 为 `string[]`） |
| `defaultValue` | `string \| string[]` | — | 非受控初始值 |
| `onValueChange` | `(value) => void` | — | 选中变化回调 |
| `variant` | `'default' \| 'outline'` | `'default'` | 下发给所有子项的样式变体 |
| `size` | `'default' \| 'sm' \| 'lg'` | `'default'` | 下发给所有子项的尺寸 |
| `disabled` | `boolean` | `false` | 禁用整组 |
| `className` | `string` | — | 附加类名（默认 `flex items-center justify-center gap-1`） |

### ToggleGroupItem

继承 `@radix-ui/react-toggle-group` Item 的全部 props。`variant` / `size` 默认继承自 `ToggleGroup` 的 Context。

| Prop | 类型 | 必填 | 说明 |
|------|------|------|------|
| `value` | `string` | 是 | 该项的值 |
| `variant` | `'default' \| 'outline'` | 否 | 覆盖组级变体（一般不用，走继承） |
| `size` | `'default' \| 'sm' \| 'lg'` | 否 | 覆盖组级尺寸 |
| `disabled` | `boolean` | 否 | 禁用该项 |
| `className` | `string` | 否 | 附加类名 |

## 示例

### 单选视图切换（列表 / 网格）

```tsx
const [view, setView] = useState<'list' | 'grid'>('list')

<ToggleGroup
  type="single"
  value={view}
  onValueChange={(v) => v && setView(v as 'list' | 'grid')}
  variant="outline"
  size="sm"
>
  <ToggleGroupItem value="list" aria-label="列表视图">
    <List className="h-4 w-4" />
  </ToggleGroupItem>
  <ToggleGroupItem value="grid" aria-label="网格视图">
    <LayoutGrid className="h-4 w-4" />
  </ToggleGroupItem>
</ToggleGroup>
```

### 多选筛选（资源类型）

```tsx
<ToggleGroup type="multiple" value={kinds} onValueChange={setKinds} size="sm">
  <ToggleGroupItem value="Deployment">Deployment</ToggleGroupItem>
  <ToggleGroupItem value="StatefulSet">StatefulSet</ToggleGroupItem>
  <ToggleGroupItem value="DaemonSet">DaemonSet</ToggleGroupItem>
</ToggleGroup>
```

## 注意事项

- `type="single"` 允许全部取消选中，此时 `onValueChange` 回传空字符串，需自行兜底（示例中 `v && setView(...)`）。
- 变体统一走组级 `variant` / `size`，子项一般不必单独指定。
