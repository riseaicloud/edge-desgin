# Select 下拉选择

平台下拉的**唯一推荐入口**。一行用法，单选 / 多选 / 搜索 / 远程分页全部在 props 上，
内部按 props 自动路由到合适的引擎（固定枚举走 Radix，数据型走 combobox）。

**选型口诀**：固定枚举（≤10 项写死的）直接用；选项多或来自接口，加 `searchable`；
业务选择器（选集群 / 镜像 / 用户）用 `@riseaicloud/components` 的成品，别在页面里拼。

## 远程搜索 + 滚动分页

提供 `onSearch` 切换为远程模式（内部防抖 300ms），`onLoadMore`/`hasMore`/`loading`
组成滚动分页。**不要手写这套状态机**——用 `@riseaicloud/hooks` 的 `useSelectOptions`
一行接入，翻页、搜索重置、竞态丢弃都在 hook 里：

```tsx
const users = useSelectOptions((p) =>
  api.listUsers({ page: p.page, pageSize: p.pageSize, keyword: p.query })
)

<Select searchable placeholder="选择用户" value={v} onValueChange={setV} {...users.selectProps} />
```

fetcher 参数字典（前后端约定）：

| 模式 | 请求 | 响应 | hasMore |
| --- | --- | --- | --- |
| 常规 BFF（默认） | `page`(1 起) / `pageSize` / `keyword` | `{ items, total }` | `page × pageSize < total` |
| K8s 风格 | `limit` / `continue` / `keyword` | `{ items, continue }` | `continue` 非空 |

## 选项 icon 与对钩位置

`options[].icon` 支持 icon+文本；`checkAlign="right"` 把选中对钩挪到最右（默认在左）。

```tsx
<Select options={[{ value: 'gpu', label: 'GPU 节点', icon: <Dot /> }]} checkAlign="right" … />
```

## 联动（级联）

联动是页面层的接线，组件零专用 API：下游的 fetcher 闭包引用上游的值；
上游变化时**清空下游选中 + `reload()`**。

```tsx
const pools = useSelectOptions((p) => api.listPools({ cluster, ...p }))

<Select options={clusters} value={cluster}
        onValueChange={(v) => { setCluster(v); setPool(''); pools.reload() }} />
<Select searchable value={pool} onValueChange={setPool} {...pools.selectProps} />
```

## API

### Select（门面）

| Prop | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `options` | `SelectOption[]` | — | `{ value, label, icon?, disabled? }`；value 不可为空串 |
| `value` / `onValueChange` | `string` / `(v) => void` | — | 单选 |
| `multiple` + `values` / `onValuesChange` | `boolean` + `string[]` | `false` | 多选（点选项不关浮层） |
| `searchable` | `boolean` | 见说明 | 搜索框；提供 `onSearch`/`filterOption` 时自动开启 |
| `onSearch` | `(q) => void` | — | 远程搜索（防抖 300ms），父方返回过滤后的 options |
| `onLoadMore` / `hasMore` / `loading` | — | — | 滚动分页三件套（配 `useSelectOptions`） |
| `clearable` | `boolean` | `false` | 清空按钮 |
| `checkAlign` | `'left' \| 'right'` | `'left'` | 选中对钩位置 |
| `renderOption` | `(opt, selected) => ReactNode` | — | 自定义选项渲染 |
| `placeholder` / `disabled` / `width` / `className` | — | — | 常规 |

**props 白名单纪律**：只收中性能力。`tags` / `labelInValue` / 自由输入等一律不加；
「数据从哪来」的业务语义归 `@riseaicloud/components`。
