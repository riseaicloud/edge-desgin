# ResourceChart 资源使用率图表

`ResourceChart` 是开箱即用的资源使用率卡片，用于展示 CPU、内存、磁盘、GPU 等资源的实时占用与历史趋势。一个卡片同时包含：标题、当前值、百分比大数字、进度条（按阈值自动变色）以及底部时间序列面积图。内部基于 [`ChartContainer`](./chart) 与 recharts 封装。

## 引入

```tsx
import { ResourceChart } from '@riseaicloud/ui'
import type { ResourceChartProps, ResourceChartDataPoint } from '@riseaicloud/ui'
```

## Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `title` | `string` | 必填 | 图表标题（如「CPU 使用率」） |
| `currentValue` | `string` | 必填 | 当前使用值（带单位的字符串，如 `"2.4 cores"`），显示在百分比下方 |
| `percentage` | `number` | 必填 | 使用百分比，用于大数字与进度条宽度 |
| `timeSeries` | `ResourceChartDataPoint[]` | 必填 | 时间序列数据 |
| `color` | `string` | `'#3b82f6'` | 面积图主题色（线条与填充） |
| `unit` | `string` | `'%'` | 数值单位，用于大数字、Y 轴刻度和 Tooltip |
| `showGrid` | `boolean` | `true` | 是否显示背景网格线 |
| `className` | `string` | — | 附加类名（叠加在白底卡片外层） |

> **进度条自动配色**：`percentage > 80` 红色、`> 60` 黄色、其余蓝色；宽度按 `min(percentage, 100)%` 计算。

### 类型

```typescript
interface ResourceChartDataPoint {
  time: string | number   // 时间戳或时间标签（作为 X 轴 dataKey）
  value: number           // 数值（作为面积图 dataKey）
}
```

## 示例

### CPU 使用率

```tsx
const cpuTimeSeries: ResourceChartDataPoint[] = [
  { time: '10:00', value: 45 },
  { time: '10:05', value: 52 },
  { time: '10:10', value: 62 },
]

<ResourceChart
  title="CPU 使用率"
  currentValue="2.4 cores"
  percentage={62.5}
  timeSeries={cpuTimeSeries}
  color="#3b82f6"
  unit="%"
/>
```

### 内存使用率（自定义配色）

```tsx
<ResourceChart
  title="内存使用率"
  currentValue="12.8 / 16 GiB"
  percentage={80}
  timeSeries={memTimeSeries}
  color="#8b5cf6"
/>
```

`percentage` 达到 80 时进度条转为黄色，超过 80 转为红色，用于直观提示资源紧张。

### 资源概览网格

```tsx
<div className="grid grid-cols-1 md:grid-cols-2 gap-4">
  <ResourceChart title="CPU 使用率"  currentValue="2.4 cores"    percentage={cpu}  timeSeries={cpuSeries} />
  <ResourceChart title="内存使用率" currentValue="12.8 GiB"    percentage={mem}  timeSeries={memSeries} color="#8b5cf6" />
  <ResourceChart title="GPU 使用率"  currentValue="6 / 8"        percentage={gpu}  timeSeries={gpuSeries} color="#10b981" />
  <ResourceChart title="磁盘使用率" currentValue="240 / 500 GB" percentage={disk} timeSeries={diskSeries} color="#f59e0b" />
</div>
```

## 注意事项

- `currentValue` 与 `percentage` 是相互独立的入参：大数字展示 `percentage`，副文本展示 `currentValue`，两者需由调用方保证语义一致。
- `timeSeries` 每项须同时含 `time` 和 `value`，字段名固定，不可自定义。
- 卡片自带卡片底色（`bg-card`）、边框和 `p-4` 内边距，放入浅色列表页背景即成卡片，无需额外包裹。
