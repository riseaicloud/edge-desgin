# ProgressRing 环形进度条

`ProgressRing` 是纯 SVG 实现的环形进度组件，用于 KPI 卡片、资源占用仪表、健康度等需要在圆环中心叠加数值/图标的场景。圆环从 12 点方向顺时针填充（通过 `-rotate-90` 实现），弧线端点为圆头，进度变化带 300ms 过渡动画。传入 `value` 会被自动 clamp 到 0–100。

## 引入

```tsx
import { ProgressRing } from '@riseaicloud/ui'
import type { ProgressRingProps } from '@riseaicloud/ui'
```

## Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `value` | `number` | 必填 | 进度百分比（0–100），越界自动 clamp |
| `size` | `number` | `65` | SVG 边长（像素），圆环直径 |
| `strokeWidth` | `number` | `6` | 圆环线宽 |
| `color` | `string` | `'#52c41a'` | 进度弧颜色 |
| `trackColor` | `string` | `'#e5e7eb'` | 背景轨道颜色 |
| `children` | `ReactNode` | — | 圆环中心叠加内容（数值、百分号、图标等） |
| `className` | `string` | — | 附加类名（作用于最外层 `inline-flex` 容器） |

### 类型

```typescript
interface ProgressRingProps {
  value: number          // 进度百分比 (0-100)
  size?: number          // SVG 尺寸（像素），默认 65
  strokeWidth?: number   // 圆环线宽，默认 6
  color?: string         // 进度弧颜色，默认 #52c41a
  trackColor?: string    // 背景轨道颜色，默认 #e5e7eb
  children?: React.ReactNode  // 圆环中心内容
  className?: string
}
```

## 示例

### 基础用法（中心显示百分比）

```tsx
<ProgressRing value={72}>
  <span className="text-sm font-medium text-foreground">72%</span>
</ProgressRing>
```

### 资源占用（按阈值变色）

```tsx
<ProgressRing
  value={usage}
  size={80}
  strokeWidth={8}
  color={usage > 80 ? '#f5222d' : usage > 60 ? '#faad14' : '#52c41a'}
>
  <div className="text-center">
    <div className="text-lg font-semibold">{usage}%</div>
    <div className="text-xs text-muted-foreground">已用</div>
  </div>
</ProgressRing>
```

### 小尺寸内嵌卡片

```tsx
<ProgressRing value={45} size={48} strokeWidth={4}>
  <span className="text-xs">45%</span>
</ProgressRing>
```

## 注意事项

- `value` 是百分比（0–100），组件内部会 clamp，无需外部再限制范围。
- 中心内容需自行居中控制字号，组件仅提供绝对定位的居中容器。
- 需要线性进度条请改用 `Progress`。
