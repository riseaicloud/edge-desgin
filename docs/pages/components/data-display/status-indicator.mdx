# StatusIndicator 状态指示灯

`StatusIndicator` 用一个带颜色的小圆点（可选文字标签、可选呼吸动画）来表示资源的运行状态。相比纯文字，它在列表、表格、卡片中能一眼传达「健康 / 告警 / 异常」等语义。提供 6 种语义色和 3 种尺寸，`animated` 开启后圆点外圈会有 `ping` 呼吸扩散效果，适合标记「进行中」的实时状态。

## 引入

```tsx
import { StatusIndicator } from '@riseaicloud/ui'
import type { StatusIndicatorProps, StatusVariant } from '@riseaicloud/ui'
```

## Props

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `variant` | `StatusVariant` | `'default'` | 状态语义色，见下表 |
| `animated` | `boolean` | `false` | 是否显示呼吸（ping）动画 |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | 圆点尺寸 |
| `label` | `string` | — | 圆点右侧文字标签（`text-sm`），省略则只显示圆点 |
| `className` | `string` | — | 外层容器附加类名 |

### 语义色（variant）

| 变体 | 圆点色 | 典型语义 |
|------|--------|---------|
| `success` | 绿色 `bg-green-500` | 运行中、就绪、健康 |
| `warning` | 黄色 `bg-yellow-500` | 告警、降级、资源紧张 |
| `error` | 红色 `bg-red-500` | 失败、异常、离线 |
| `info` | 蓝色 `bg-blue-500` | 处理中、提示信息 |
| `neutral` | 灰色 `bg-muted-foreground` | 未知、待定 |
| `default` | 灰色 `bg-muted-foreground` | 默认（同 neutral） |

:::info 为什么状态色不是语义 token
绿/黄/红/蓝四个状态色**故意保留 Tailwind 色值、不走 `--primary` 一类主题 token**：色相本身就是语义（绿=健康、红=故障），
它不该随品牌主题或明暗反转——换个粉色主题不能把"运行中"变成粉点。**灰色是例外**：中性态表达的是"无信息"，
必须跟着前景色反转，否则暗色下灰点糊在暗底上，所以只有它用 `bg-muted-foreground`。
:::

### 尺寸（size）

| 尺寸 | 圆点大小 |
|------|---------|
| `sm` | `h-1.5 w-1.5`（6px） |
| `md` | `h-2 w-2`（8px） |
| `lg` | `h-3 w-3`（12px） |

### 类型

```typescript
type StatusVariant = 'success' | 'warning' | 'error' | 'info' | 'neutral' | 'default'
```

## 示例

### 表格中标注节点状态

```tsx
<TableCell>
  <StatusIndicator
    variant={node.ready ? 'success' : 'error'}
    label={node.ready ? '就绪' : '离线'}
  />
</TableCell>
```

### 训练任务进行中（呼吸动画）

```tsx
<StatusIndicator variant="info" animated label="训练中" />
```

### 纯圆点（无标签，紧凑列表）

```tsx
<div className="flex items-center gap-2">
  <StatusIndicator variant="warning" size="sm" />
  <span>{workspace.aliasName}</span>
</div>
```

## 注意事项

- 不传 `label` 时只渲染圆点，适合空间紧凑的场景。
- `animated` 建议仅用于「进行中/实时」状态，静态状态（成功/失败）无需动画，避免视觉干扰。
- 若需要带背景色的文字标签而非圆点，改用 [Badge](./badge.md)。
