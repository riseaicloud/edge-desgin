# DataTable 通用表格组件

`DataTable` 是平台统一的列表页表格组件，封装了搜索、分页、列显隐、行选择、批量操作、行内操作、导出等能力。内置 `static` 和 `remote` 两种模式，业务层只需配置列定义和数据即可。

## 引入

```tsx
import { DataTable } from '@riseaicloud/ui'
import type { ColumnDef, RowAction, BatchAction, DeleteConfig, ExportConfig, SearchFilter } from '@riseaicloud/ui'
```

## 两种模式

| 模式 | `mode` | 分页 / 搜索 | 适用场景 |
|------|--------|------------|---------|
| 静态 | `'static'` | 组件内部处理，无额外请求 | 一次性拉全量数据，数据量较小 |
| 远程 | `'remote'` | 外部控制，翻页 / 搜索触发回调 | 后端分页，数据量大 |

默认值为 `'remote'`。

## Props

### 数据

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `data` | `T[]` | 必填 | 表格数据 |
| `loading` | `boolean` | `false` | 显示加载遮罩 |
| `mode` | `'static' \| 'remote'` | `'remote'` | 数据模式 |
| `rowKey` | `string` | `'name'` | 行唯一标识字段名 |
| `emptyText` | `string` | `'暂无数据'` | 空状态文字 |

### 列定义

| Prop | 类型 | 说明 |
|------|------|------|
| `columns` | `ColumnDef<T>[]` | 列配置，见下方类型说明 |

### 分页（remote 模式需手动传入）

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `currentPage` | `number` | — | 当前页码 |
| `pageSize` | `number` | `10` | 每页条数 |
| `totalItems` | `number` | — | 总条数 |
| `pageSizes` | `number[]` | `[10,20,50,100]` | 每页条数选项 |
| `onPageChange` | `(page: number) => void` | — | 翻页回调 |
| `onPageSizeChange` | `(size: number) => void` | — | 切换每页条数回调 |

### 行操作

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `rowActions` | `RowAction<T>[] \| ((row: T) => RowAction<T>[])` | — | 行操作按钮，可按行动态返回 |
| `collapsedActions` | `boolean` | `true` | 超出数量时收起到 `⋯` 菜单 |
| `maxVisibleActions` | `number` | `1` | 最多直接显示几个操作按钮 |
| `actionsTitle` | `string` | `''` | 操作列表头文字 |
| `stickyActions` | `boolean` | `true` | 操作列固定在右侧 |
| `actionsWidth` | `number` | `120` | 操作列宽度（px）。fixed 布局无法按内容自适应，操作项较多时调大 |
| `deleteConfig` | `DeleteConfig<T>` | — | 内置删除操作（带确认弹窗） |

### 批量操作

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `batchActions` | `BatchAction<T>[]` | — | 勾选行后显示在工具栏 |
| `showSelection` | `boolean` | `false` | 是否显示行复选框 |
| `onSelectionChange` | `(rows: T[]) => void` | — | 选中行变化回调 |

### 工具栏插槽

工具栏从左到右顺序：`[搜索框] → [toolbarLeft] → [batchActions] → [列显隐] → [导出] → [刷新] → [toolbarRight]`

| Prop | 类型 | 位置 | 说明 |
|------|------|------|------|
| `toolbarLeft` | `ReactNode` | 搜索框右侧 | 通常放「创建」按钮 |
| `toolbarRight` | `ReactNode` | 最末端 | 通常放视图切换等 |

### 内置功能开关

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `showRefresh` | `boolean` | `false` | 显示刷新按钮 |
| `showColumnToggle` | `boolean` | `false` | 显示列显隐开关 |
| `exportConfig` | `ExportConfig<T>` | — | 启用 CSV 导出 |
| `onRefresh` | `() => void` | — | 刷新回调 |
| `onSearch` | `(filters: SearchFilter[]) => void` | — | remote 模式下搜索变化回调 |

### 样式

| Prop | 类型 | 说明 |
|------|------|------|
| `minWidth` | `number` | 表格最小宽度（px）。不传时自动 = 各列宽之和；传了则覆盖 |
| `className` | `string` | 覆盖外层容器 className |

## 类型定义

### ColumnDef

```typescript
interface ColumnDef<T = any> {
  key: string
  title: string
  width?: number | string                            // 数字为 px，字符串如 '20%'
  fixed?: 'left' | 'right'                            // 左/右固定（column pinning），横向滚动时保持可见
  hide?: boolean                                     // 默认隐藏，用户可通过列显隐恢复
  className?: string
  render?: (row: T, index: number) => ReactNode
  exportFormatter?: (row: T) => string               // 导出文本，优先级最高
  searchable?: boolean                               // 是否加入搜索栏
  searchType?: 'text' | 'select'                    // 搜索类型，默认 'text'
  searchOptions?: { label: string; value: string }[] // searchType='select' 时的选项
}
```

**列宽与横向滚动规则**（`table-layout: fixed`）：

- 设置了 `width` 的列**严格**按指定宽度渲染。
- 未设 `width` 的列**兜底 150px**（fixed 布局下每列必须有确定宽度，否则会塌陷、内容重叠/换行）。要控制某列宽度就给它设 `width`。
- 表格 `min-width` = 各列宽之和。**容器变窄时整表横向滚动**（而非压窄换行）；容器够宽时列按比例填满。
- 表头文字不换行（`whitespace-nowrap`）。

**列固定（column pinning）**：列设 `fixed: 'left' | 'right'` 即在横向滚动时保持贴边可见。

- 多个同侧固定列按各自 `width` 自动叠加偏移，不重叠 → **固定列建议设 numeric `width`**（否则按 150 兜底计算偏移）。
- 有左固定列时，行首复选框列自动一起左固定。
- 操作列默认右固定（`stickyActions`），右固定的数据列会自动叠在其左侧。

### RowAction

```typescript
interface RowAction<T = any> {
  label: string
  danger?: boolean
  disabled?: boolean | ((row: T) => boolean)
  hidden?: boolean | ((row: T) => boolean)
  tooltip?: string | ((row: T) => string)
  onClick: (row: T, index: number) => void
}
```

### DeleteConfig

```typescript
interface DeleteConfig<T = any> {
  rowKey?: string           // 唯一 key 字段，默认 'name'
  rowNameKey?: string       // 确认弹窗显示的名称字段，默认同 rowKey
  confirmTitle?: string
  confirmText?: string | ((row: T) => string)
  onDelete: (row: T) => Promise<void>
  disabled?: (row: T) => boolean
  hidden?: (row: T) => boolean
  buttonText?: string       // 默认 '删除'
}
```

### BatchAction

```typescript
interface BatchAction<T = any> {
  label: string
  disabled?: (selected: T[]) => boolean  // 传入所有选中行，返回是否禁用
  onClick: (selected: T[]) => void       // 传入所有选中行
}
```

### ExportConfig

```typescript
interface ExportConfig<T = any> {
  filename?: string                                              // 不含 .csv 后缀
  customExport?: (data: T[], columns: ColumnDef<T>[]) => string[][]
}
```

### SearchFilter

```typescript
interface SearchFilter {
  key: string    // 列的 key
  value: string  // 搜索值
}
```

## 导出逻辑

导出始终包含**全部列**（不受列显隐开关影响），文本提取优先级：

1. `exportFormatter(row)` — 最高优先级，精确控制
2. `render(row)` — 自动递归提取 React 节点中的文本
3. `row[key]` — 字段值兜底

:::tip
`render` 中包含图标、SVG 等无文字内容时，建议补充 `exportFormatter` 明确指定导出值。
:::

## 搜索行为

### 单字段搜索

只有一列 `searchable: true` 时，显示普通输入框，实时过滤（static 模式）或实时触发 `onSearch`（remote 模式）。

### 多字段搜索

两列及以上 `searchable: true` 时，显示 chip 搜索栏：

- 点击搜索栏打开下拉面板，顶部 tab 切换当前搜索字段
- `text` 类型：输入后 Enter 提交，生成 chip
- `select` 类型：面板展示选项列表，点击直接提交
- 同一字段再次选值会替换已有 chip
- Backspace 删除最后一个 chip
- 多个 chip 之间为 AND 关系

## 使用示例

### 最简静态表格

```tsx
const columns: ColumnDef<Item>[] = [
  { key: 'name', title: '名称' },
  { key: 'status', title: '状态' },
]

<DataTable data={list} mode="static" rowKey="id" columns={columns} />
```

### 多字段搜索（含下拉选项）

```tsx
const columns: ColumnDef<Item>[] = [
  { key: 'name', title: '名称', searchable: true },
  {
    key: 'status', title: '状态',
    searchable: true, searchType: 'select',
    searchOptions: [
      { label: '运行中', value: 'Running' },
      { label: '已停止', value: 'Stopped' },
    ],
    render: (row) => <StatusBadge status={row.status} />,
    exportFormatter: (row) => statusLabel[row.status] ?? row.status,
  },
]

<DataTable data={list} mode="static" rowKey="id" columns={columns} />
```

### 行操作 + 内置删除

```tsx
const rowActions = (row: Item) => [
  { label: '查看详情', onClick: () => navigate(`/detail/${row.id}`) },
  ...(row.status === 'Running' ? [{ label: '停止', onClick: () => stop(row) }] : []),
]

<DataTable
  data={list}
  mode="static"
  rowKey="id"
  columns={columns}
  rowActions={rowActions}
  collapsedActions
  maxVisibleActions={1}
  actionsTitle="操作"
  deleteConfig={{
    confirmTitle: '删除实例',
    confirmText: '删除后无法恢复，请确认。',
    onDelete: async (row) => { await api.delete(row.id); refresh() },
    hidden: (row) => row.status !== 'Stopped',
  }}
/>
```

### 批量操作

```tsx
const batchActions: BatchAction<Item>[] = [
  {
    label: '批量关机',
    disabled: (selected) => selected.every(r => r.status === 'Stopped'),
    onClick: async (selected) => {
      if (!confirm(`确定关机 ${selected.length} 项？`)) return
      await Promise.all(selected.map(r => api.stop(r.id)))
      refresh()
    },
  },
  {
    label: '释放资源',
    disabled: (selected) => selected.some(r => r.status !== 'Stopped' && r.status !== 'Pending'),
    onClick: async (selected) => {
      if (!confirm(`确定释放 ${selected.length} 项？`)) return
      await Promise.all(selected.map(r => api.delete(r.id)))
      refresh()
    },
  },
]

<DataTable
  data={list}
  mode="static"
  rowKey="id"
  columns={columns}
  showSelection
  batchActions={batchActions}
/>
```

### 工具栏插槽 + 导出

```tsx
<DataTable
  data={list}
  mode="static"
  rowKey="id"
  columns={columns}

  showColumnToggle
```

### Remote 模式（后端分页 + 服务端搜索）

```tsx
const [page, setPage] = useState(1)
const [pageSize, setPageSize] = useState(10)
const [total, setTotal] = useState(0)
const [filters, setFilters] = useState<SearchFilter[]>([])

useEffect(() => {
  api.list({ page, pageSize, filters }).then(res => {
    setList(res.items)
    setTotal(res.total)
  })
}, [page, pageSize, filters])

<DataTable
  data={list}
  mode="remote"
  rowKey="id"
  columns={columns}
  currentPage={page}
  pageSize={pageSize}
  totalItems={total}
  onPageChange={setPage}
  onPageSizeChange={(s) => { setPageSize(s); setPage(1) }}
  onSearch={(f) => { setFilters(f); setPage(1) }}
/>
```

### 默认隐藏列

```tsx
const columns: ColumnDef<Item>[] = [
  { key: 'name', title: '名称' },
  { key: 'id', title: 'ID', hide: true },  // 默认隐藏，用户可通过列显隐恢复
]
```

### 列固定 + 横向滚动（列多时）

```tsx
const columns: ColumnDef<Item>[] = [
  { key: 'name', title: '名称 / ID', fixed: 'left', width: 240, render: (r) => <NameId row={r} /> },
  { key: 'status', title: '状态', width: 120, render: (r) => <Badge s={r.status} /> },
  { key: 'flavor', title: '算力规格', width: 120 },
  { key: 'gpu', title: 'GPU', width: 100 },
  { key: 'image', title: '镜像', width: 160 },
  { key: 'creator', title: '创建人' },      // 未设 width → 兜底 150
  { key: 'createdAt', title: '创建时间' },
  { key: 'ssh', title: '远程访问', fixed: 'right', width: 120, render: (r) => <SshLink row={r} /> },
]

<DataTable
  data={list} mode="static" rowKey="id" columns={columns}
  rowActions={rowActions} actionsTitle="操作" actionsWidth={160}  // 操作项多 → 调大
/>
// 窄屏时：名称/ID 左固定、远程访问 + 操作 右固定，中间列横向滚动。
```

## 注意事项

- `mode="static"` 时不需要传 `currentPage` / `totalItems` / `onPageChange`，组件内部管理
- `deleteConfig` 与 `rowActions` 中手动写的删除操作**不要重复**，会出现两个删除项
- 泛型 `DataTable<T>` 会从 `data` 推断行类型，`columns` 的 `render` 因此获得完整类型提示，一般不需要手写类型参数
