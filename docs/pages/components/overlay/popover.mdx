# Popover 浮层面板

`Popover` 是对 [Radix UI Popover](https://www.radix-ui.com/primitives/docs/components/popover) 的封装，用于点击触发后弹出一个带边框、阴影的浮层面板，承载筛选表单、快捷操作、颜色选择等轻量交互内容。与 `Tooltip`（悬停、纯展示）不同，`Popover` 是点击触发、可交互、可聚焦的。内容走 Radix Portal 渲染，默认宽度 `w-72`（18rem）。

## 引入

```tsx
import { Popover, PopoverTrigger, PopoverAnchor, PopoverContent } from '@riseaicloud/ui'
```

## Props

`Popover` / `PopoverTrigger` / `PopoverAnchor` 均为 Radix 原语直接透传，**继承 Radix UI 对应 primitive 的全部 props**。

### Popover（= `Popover.Root`）

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `open` | `boolean` | — | 受控展开状态 |
| `defaultOpen` | `boolean` | `false` | 非受控初始展开 |
| `onOpenChange` | `(open: boolean) => void` | — | 展开状态变化回调 |
| `modal` | `boolean` | `false` | 是否模态（拦截外部交互并锁滚动） |

### PopoverTrigger（= `Popover.Trigger`）

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `asChild` | `boolean` | `false` | 将子元素作为触发器，不额外包一层 DOM |

### PopoverAnchor（= `Popover.Anchor`）

可选定位锚点。不传时浮层以 `PopoverTrigger` 为锚点定位；需要触发器与定位参照分离时使用。**继承 Radix `Anchor` 全部 props**。

### PopoverContent（本组件包装）

在 Radix `Content` 上预置了样式并**自带 `Popover.Portal`**，**继承 Radix `Content` 全部 props**。

| Prop | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `align` | `'start' \| 'center' \| 'end'` | `'center'` | 相对锚点的对齐方式 |
| `sideOffset` | `number` | `4` | 与锚点的间距（像素） |
| `side` | `'top' \| 'right' \| 'bottom' \| 'left'` | `'bottom'` | 弹出方向 |
| `className` | `string` | — | 附加类名（覆盖默认 `w-72`、内边距等） |

## 示例

### 快捷筛选面板

```tsx
<Popover>
  <PopoverTrigger asChild>
    <Button variant="outline" size="sm">
      <Filter className="h-4 w-4 mr-1" /> 筛选
    </Button>
  </PopoverTrigger>
  <PopoverContent align="start" className="w-80">
    <div className="space-y-3">
      <div className="text-sm font-medium">按状态筛选</div>
      {/* 表单控件 */}
    </div>
  </PopoverContent>
</Popover>
```

### 受控展开（选完即关）

```tsx
const [open, setOpen] = useState(false)

<Popover open={open} onOpenChange={setOpen}>
  <PopoverTrigger asChild>
    <Button variant="outline">{cluster || '选择集群'}</Button>
  </PopoverTrigger>
  <PopoverContent className="p-0 w-64">
    <ClusterList onPick={(c) => { setCluster(c); setOpen(false) }} />
  </PopoverContent>
</Popover>
```

## 注意事项

- `PopoverContent` 已内置 `Popover.Portal`，渲染到 `body` 末尾。注意 portal 依赖宿主的 `react-dom` 实例——微前端场景下宿主与子应用必须共用同一份 `react-dom`，否则浮层不显示。
- 面板内含表单需要占满时，通过 `className` 覆盖默认 `w-72` 与 `p-4`（例如 `className="p-0 w-80"`）。
